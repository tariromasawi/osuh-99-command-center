## What runs when the page is closed

A browser cannot keep JavaScript or the 432 Hz tone alive after the tab is shut. That is a hard limit of every browser.

The **perpetual loop** therefore runs on GitHub Actions:

- Workflow: `.github/workflows/perpetual-loop.yml`
- Schedule: minute 33 of every hour (77-99-**33**)
- Output: `STATUS.md` is rewritten on each pulse
- Manual run: Actions → OSUH-99 Perpetual Loop → Run workflow

Enable Actions on first visit to the Actions tab if GitHub asks.
